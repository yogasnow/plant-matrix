# Где код и на чём остановились

## Написанное

Исходники были созданы локально в `output/plant-matrix-core-2026-10-08/` и перенесены сюда как **`tools/make_cards.py`** и **`tools/make_atlas_science.py`**. Язык — Python, библиотека — Pillow. Первый скрипт рисует восемь PNG-карточек в `cards/`; второй собирает семистраничный `plant-matrix-atlas-01-nutrition.pdf`. Это генераторы визуальных учебных материалов, **не** сайт и не программа для автоматического подбора питания.

```bash
python3 -m pip install Pillow
python3 tools/make_cards.py
python3 tools/make_atlas_science.py
```

Скрипты используют системные шрифты DejaVu Sans (`/usr/share/fonts/truetype/dejavu/`). Результаты генерации уже включены в репозиторий, поэтому для просмотра Python не нужен.

## Достигнутая точка

Основная серия: **01 атом → 02 молекула → 03 клетка → 04 ткань → 05 мембрана → 06 строение клетки → 07 ядро и ДНК → 08 РНК и рибосома**. Атлас расширяет маршрут на питание и грибы и объясняет границы научных выводов. Карточки используют вопрос и символическую награду; логики настоящей интерактивной игры ещё нет.

## Следующий шаг в коде

1. Вынести тексты, вопросы и источники из рисунка в отдельные структурированные данные (например, JSON). Тогда содержание можно менять без правки координат в Python.
2. Создать блок **09 «Аминокислоты → пептиды → белки»** с вопросом и проверенным источником. Затем — пищеварительные ферменты и всасывание.
3. После проверки научных формулировок добавить простой просмотрщик карточек с навигацией и обратной связью по ответам.

Исследовательская карта в [атласе](atlas-01.md) — план тем, а не подтверждение клинической эффективности. Перед использованием как научного справочника нужны точные ссылки для каждого утверждения.
