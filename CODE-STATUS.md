# Код и следующий шаг

**Язык:** Python. **Библиотека:** Pillow. **Файл:** [`tools/make_cards.py`](tools/make_cards.py). Скрипт создаёт восемь PNG в `cards/`; интерактивной игры или сайта пока нет.

```bash
python3 -m pip install Pillow
python3 tools/make_cards.py
```

Нужен системный шрифт DejaVu Sans. Готовые карточки уже лежат в репозитории, так что для просмотра ничего запускать не требуется.

Мы закончили **01–08**: атом → молекула → клетка → ткань → мембрана → строение клетки → ядро и ДНК → РНК и рибосома. Порядок карточек в коде теперь совпадает с порядком чтения.

**Продолжение:** добавить 09 «Аминокислоты → пептиды → белки». До новой карточки полезно вынести названия, вопросы и ответы из Python-скрипта в отдельный файл данных, чтобы редактировать содержание независимо от дизайна. К научным утверждениям нужны точные источники; лечебные интерпретации не смешиваем с базовой биологией.
