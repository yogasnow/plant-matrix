# Plant Matrix

Черновик образовательного атласа Снежаны: от атома и молекулы к клетке, тканям, питанию и грибам.

## Что уже есть

- [Атлас 01](atlas-01.md) — структура курса, первые понятия и вопросы для обучения.
- [Карточки](cards/) — восемь визуальных иллюстраций базовых понятий.
- [PDF-версия](plant-matrix-atlas-01-nutrition.pdf) — рабочая сборка атласа.

**Статус:** концепция и учебные материалы, не завершённый научно рецензированный курс. Научные утверждения и источники требуют проверки перед публичным выпуском. Материалы не предназначены для диагностики или лечения.

## Следующий этап

Составить для каждой карточки список источников, отделить установленный механизм от гипотез и провести проверку понятности с учащимися.

_Закрытый рабочий репозиторий; состав и формулировки ожидают авторского утверждения._
