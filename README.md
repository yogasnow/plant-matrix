# Plant Matrix

Открытый учебный прототип Снежаны: от атома и молекулы к клетке, тканям, питанию и грибам. Здесь собраны готовые карточки, атлас и Python-код, которым они созданы.

## Что уже есть

- [Атлас 01](atlas-01.md) — структура курса, первые понятия и вопросы для обучения.
- [Карточки](cards/) — восемь визуальных иллюстраций базовых понятий.
- [PDF-версия](plant-matrix-atlas-01-nutrition.pdf) — рабочая сборка атласа.
- [Карта кода и точка остановки](CODE-STATUS.md) — какие скрипты написаны, что они производят и какой блок следующий.
- [Генератор карточек](tools/make_cards.py) и [генератор PDF](tools/make_atlas_science.py) — Python + Pillow.

**Статус:** публичный учебный черновик, не научно рецензированный курс. Утверждения и ссылки на источники ещё требуют построчной проверки. Материалы не предназначены для диагностики или лечения.
