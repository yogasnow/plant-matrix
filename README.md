1. [Атом](cards/01-atom.png)

Каждая карточка содержит понятие, связь с предыдущим шагом и проверочный вопрос. [Исходный Python-код](tools/make_cards.py) создаёт изображения с помощью Pillow; [как запустить и что дальше](CODE-STATUS.md).

**Точка остановки:** карточка 08. Следующая тема — **09: аминокислоты → пептиды → белки**. Биохакинг и другие ветки пока не включены в основную цепочку.

Это публичный учебный черновик, не медицинская рекомендация и не научно рецензированный курс. Лицензия на повторное использование не указана.
