# Plant Matrix · основная цепочка

Восемь учебных карточек Снежаны: от атома к синтезу белка. Открой по порядку:

**Быстрый вход:** [посмотреть первую карточку](cards/01-atom.png) → [открыть Python-код](tools/make_cards.py) → **статус:** карточки 01–08 готовы → **дальше:** подготовить карточку 09 об аминокислотах, пептидах и белках.

2. [Молекула](cards/02-molecule.png)

4. [Ткань](cards/04-tissue.png)

7. [Ядро и ДНК](cards/07-nucleus-dna.png)
8. [РНК и рибосома](cards/08-rna-ribosome.png)

Каждая карточка содержит понятие, связь с предыдущим шагом и проверочный вопрос. [Исходный Python-код](tools/make_cards.py) создаёт изображения с помощью Pillow; [как запустить и что дальше](CODE-STATUS.md).

**Точка остановки:** карточка 08. Следующая тема — **09: аминокислоты → пептиды → белки**. Биохакинг и другие ветки пока не включены в основную цепочку.

## Дополнительный атлас

[Plant Matrix · атлас 01: нутрициология (PDF, 7 страниц)](atlas/plant-matrix-atlas-01-nutrition.pdf) — отдельный обзор питания, клеточных процессов и грибов, присланный Снежаной. Он расширяет контекст, но не меняет порядок карточек 01–08 и не заменяет проверку научных источников.

**Маршрут работы:** прочитать карточки 01–08 → проверить вопрос на каждой → открыть [код генератора](tools/make_cards.py) → подготовить содержание и источники для карточки 09. Сначала продолжаем базовую биологию; связь с биохакингом — позднее.

Это публичный учебный черновик, не медицинская рекомендация и не научно рецензированный курс. Лицензия на повторное использование не указана.
